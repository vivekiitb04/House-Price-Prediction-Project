# House-Price-Prediction-Project
• Performed Exploratory Data Analysis and feature engineering on property records, creating features such as house age,
renovation status, total living area, grade, location and area-utilization ratios to capture key factors influencing house prices.
• Implemented Linear Regression, Ridge, Lasso, Decision Tree and Random Forest models with appropriate preprocessing,
handled missing values and one-hot encoding; evaluated models using R2-score, adj R2 score, MAE and RMSE.
• Applied GridSearchCV for Hyperparameter Tuning with Random Forest achieving the R2-score = 0.84, adj R2-score=0.84,
MAE= 73183.4andRMSE=151204.77followed by Ridge with R2-score =0.81, MAE=97083.43andRMSE=168213.29.
